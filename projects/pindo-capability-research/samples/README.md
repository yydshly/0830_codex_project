# Pindo 场景样例输入

这些输入均为本研究项目原创 SVG，用于在固定上游提交
`5b6c85c3cb1bbf72b5f4ce91365a4cd61a9fad39` 上复现实验。它们不来自 Pindo
仓库，也不复制上游界面或源码。

| 输入 | 目标场景 | 主要观察 |
| --- | --- | --- |
| `portrait-gradient.svg` | 普通插画转拼豆图纸 | 渐变、肤色、五官在有限色板和网格下如何简化 |
| `pixel-mascot.svg` | 低分辨率像素素材 | 硬边、小色数和轮廓是否能被保留 |
| `grid-heart.svg` | 有稳定网格的旧图纸识别 | 能否自动恢复实际网格尺寸并匹配色号 |
| `grid-heart-skewed.svg` | 倾斜拍摄边界 | 自动网格检测失败时是否退回用户宽高切分 |

SVG 只承担输入角色；网页中的 Pindo 实测指标来自浏览器实际上传这些文件后的观察。
