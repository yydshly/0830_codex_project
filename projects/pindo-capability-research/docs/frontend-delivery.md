# Pindo 能力研究页：前端交付契约

## 设计契约

- Entry mode：Revision-led；保留既有研究、质量与产品机会内容，把 Together 假设推进为“九豆记忆灯”可操作原型。
- Request revision：14。
- Target user and context：希望保存共同记忆的伴侣、家人或朋友，以及需要判断该方向能否成为真实产品的产品负责人；典型用户已有照片、纪念物、名字或一句只属于两个人的话。
- Desired first impression：打开专用演示链接即可看到照片或文字在一颗豆中显影、退回柔光、再切换到下一段记忆；不需要先理解表单或手动准备数据。
- Visual ambition：Editorial。
- Experience architecture：Editorial Flow。
- Visual constraints：延续深棕、米白、黄色与纸张式研究卡片；复用已生成的真实场景概念照，不用表情、占位图、CSS art 或代码绘图伪装商品；产品目标区以证据和 MVP 为视觉主层，不用图片替代结论。
- Information constraints：九颗豆分别对应相遇、日常、感谢、支持、和好、成长、想念、约定、未来；内容模式覆盖情绪柔光、名字、照片、纪念物和一句话；明确概念图不等于在售商品或当前硬件。
- Operation constraints：静态 HTML/CSS/JavaScript，无后端、登录、真实上传或支付；照片仅在浏览器内缩放后写入 `localStorage`，不上传；循环控制提供顺序、随机、5/8/15 秒节奏、开始/暂停和下一颗；只播放已写入内容，手动触碰优先并暂停自动循环。
- State constraints：保留原有质量、材料、商业、情绪和生活产品状态；九豆新增停止、顺序播放、随机播放、隐藏页临时停表、手动触碰暂停、内容不足提示与 reduced-motion 无位移状态；编辑选中态与正在展示态必须分开，自动播放不得覆盖表单中的未保存输入。
- Environment constraints：作为 Research Lab 的 `web/` 静态演示发布；支持现代桌面浏览器、平板和 390px 手机；仅提供中文浅色主题。
- Primary journey：打开演示链接或点击“直接演示 30 秒” → 九颗示例以随机顺序播放 → 每颗经历记忆显影与柔光停顿 → 30 秒后自动恢复用户原有记忆与控制偏好；用户也可提前结束。
- User-defined phases：理解“拼豆”；理解 Pindo；按目标使用场景查看样例；理解产品可扩展方向；判断产品优先级；建立可复现研究子项目。
- Required artifacts：`README.md`、`project.json`、`docs/product-opportunity-map.md`、`evidence/upstream-verification.json`、`evidence/sample-cases.json`、`samples/inputs/`、`samples/outputs/`、`web/assets/`、`demo/verify_demo.py`、`web/index.html`、`web/styles.css`、`web/app.js`、本交付记录。
- Autonomy authorization：用户明确要求基于真实用户需求判断可用产品目标；允许在现有页面中收敛方向、接入公开类目证据、定义明确标注为“建议”的验证门槛，并更新可逆静态交互与文档。
- User-decision boundary：不发布、修改或再分发无明确许可证的上游源码；不调用付费服务；不替用户推送或发布。
- Observable completion criteria：顺序与随机模式、节奏、开始/暂停、下一颗和状态说明可见；循环只访问已写入豆且随机模式不连续重复；手动触碰暂停；编辑表单不随自动展示被重置；页面隐藏时不继续计时；偏好只保存模式和节奏、不自动恢复播放；既有写入交互不被删除；验证脚本、研究仓库检查和 r13 构建通过。真实跨视口视觉与键盘观察仍受当前浏览器工具边界限制，不虚报通过。
