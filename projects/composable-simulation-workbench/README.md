# 可组合红蓝仿真工作台

> **归档状态：暂时归档（2026-08-31）。** 产品目标、适用场景、可实施性、仿真语义、核心契约、总体架构和技术验证路线已经形成开发前基线；当前不进入代码实现。后续出现明确的试点场景、投入人员或接口需求时，按[归档与恢复说明](docs/07-archive-handoff.md)恢复。

本项目是 [Anthropic FDE 面试指南深度研究](../anthropic-fde-interview-guide-research/README.md)的下游落地探索：它使用 FDE 的“业务目标 → 最小闭环 → 评测证据 → 可复用产品能力”方法，研究军工仿真项目中模型、时间、指令、运动、态势和回放反复建设的问题。上游研究已经完成，本项目当前暂停。

本项目为一个新的仿真产品建立开发前置架构包。目标是在完全合成、封闭的仿真环境中，提供类似经典 RTS 的直观操作效果，同时借鉴通用仿真框架的组件化、时间管理、事件调度、日志、回放和插件扩展思想。

产品只模拟虚构阵营、通用实体和合成交互。指令仅作用于仿真世界；不连接真实装备、现实行动系统或受限网络，不使用过去公司的代码、模型、参数、场景和项目数据。

## 产品结论

产品不是完整 RTS 游戏，也不是第一版就达到验证级精度的专业分析系统。第一阶段定位为：

> 一个可扩展的实时双阵营仿真沙盘。场景制作人员可以构建模型和地图、部署多个实体、启动运行、下达仿真内部指令、观察运动与合成交互，并保存和回放完整过程，而不修改仿真内核。

核心旅程：

```text
构建模型 → 制作地图 → 编排场景 → 启动运行
→ 下达指令 → 实体运动与交互 → 态势显示
→ 暂停/单步/倍速 → 结束 → 指标与回放
```

## 第一版能力

- 一张 2D/2.5D 合成地图；
- 两个虚构阵营和数十个合成实体；
- 组件化实体与 2–3 类通用运动模型；
- 地图、模型和场景配置；
- 仿真内部指令及接受、拒绝、执行、完成、超时状态；
- 启动、暂停、恢复、单步、倍速和尽快运行；
- 实体、轨迹、时间、指令和事件态势显示；
- 事件日志、状态快照、保存、加载和确定性回放；
- 至少一个不修改内核即可安装的扩展插件。
