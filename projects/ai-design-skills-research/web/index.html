03 / State simulator

          06 / Final reading

          最终结论：保留封装方法，不再深挖普通网页规则。

          收集必要输入→ 显式选择→ 收紧可选值→ 固定输出契约→ 自动验证
          研究结项

          它适合作为 Skill 封装和团队约束的简单案例，不是高级 UI 技术或效果库。后续应投入私有设计系统、可复用动效/3D 资产，以及生成—浏览器验证—自动修改闭环。
