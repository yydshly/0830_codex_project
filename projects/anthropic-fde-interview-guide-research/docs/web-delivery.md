## 设计方向

| 决策 | 选定方向 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 信息层级 | 一句定义 → 工作闭环 → 技术架构 → 客服样例 → 面试准备 | 第一屏只保留一个主结论和三个事实 | 读者无需滚动即可回答“FDE 是什么” |

### 运行环境

```text
Canonical URL: http://127.0.0.1:4174/demos/anthropic-fde-interview-guide-research/
Browser: Chromium through agent-browser 0.27.0
Checked at: 2026-08-30, Asia/Shanghai
```

端口 4173 验收时已被另一个本地项目 `sketchbook-page-curl-study` 占用；未停止或覆盖该进程，本项目改用 4174。

### 首次观察与修复

- **观察**：首个整页截图中，尚未滚入视口的 `.reveal` 章节保持透明，形成大块空白。
- **根因**：IntersectionObserver 驱动的入场动画把核心内容可见性绑定到滚动。
- **最小干预**：移除隐藏状态，保留结构化交互；所有章节始终可读。
- **邻接检查**：重做深浅主题整页截图、桌面首屏、平板和手机截图。
- **结果**：页面从顶部到页脚连续显示，无空白章节。决定：`pass`。

### Revision 3 基线与最小干预

- **基线**：1440×900 页面有 10 个 section、8 个导航、6 个 tablist、1 个搜索输入，但没有任务判断或个人自评表单；整页高度 14,098px，主要旅程仍是单向阅读。
- **缺口**：读者能解释 FDE，却不能在页面内回答“这个任务是否需要 Agent”“项目失败在哪一层”“我下一项该补什么证据”。
- **干预**：不新增顶层导航或独立长章节，把任务适配器放入场景、交付物与失败诊断放入客服样例、证据自评放入四周路线。
- **邻接结果**：最终仍为 10 个 section 和 8 个导航；桌面整页高度约 16,111px，增加的长度对应三个可操作工具，没有复制既有概念说明。决定：`pass`。

### Revision 4 场景原型化基线与干预

## 有效延期

### JavaScript 禁用冷启动

- **尝试路线**：检查 `agent-browser` 的 browser settings 与帮助；当前版本提供 viewport、media、offline 等设置，但没有禁用 JavaScript 的新上下文能力。
- **缺失能力**：无法在同一 CLI 中创建 `javaScriptEnabled=false` 的冷启动浏览器上下文。
- **已有工程证据**：HTML 初始没有 `hidden` 属性；交互面板的默认隐藏由 `.js` 类和运行时属性控制，因此不执行脚本时核心内容按文档流全部出现。
- **重新测试触发条件**：使用可创建禁用 JavaScript 上下文的 Playwright/DevTools 环境时，重新加载 canonical URL 并检查全部 panel 可读。
- **决定**：`defer`；不影响当前静态站的主要阅读旅程。
