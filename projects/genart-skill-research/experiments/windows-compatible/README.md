# Windows 兼容性实验

上游 `scripts/lib.mjs` 在 Windows 上运行根路径请求时会失败：`path.join` 返回以反斜杠结尾的目录，但实现只检查正斜杠，因此没有追加 `index.html`。它还会在读取文件前发送 `200` 响应头，读取失败后再写 `404`，最终触发 `ERR_HTTP_HEADERS_SENT`。

这里复制上游三个脚本，只对共享服务器实现做两个最小改动：

1. 同时识别 `/` 和 `\` 目录结尾；
2. 成功读取文件后才发送 `200` 响应头。

该目录只用于验证上游脚本的预期能力，不代表上游原版已经具备 Windows 支持。
