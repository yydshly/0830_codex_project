QUESTION 00
它是图像模型、处理 SDK，还是 Agent Skill？

              

                
读取对象SKILL.md · subject-diagnostics.md · production-prompt.md
检查是否存在模型权重、推理代码、API、批处理或独立运行入口。

                
观察结果它是一套摄影工作流与质量约束
核心由诊断分支、身份不变量、灯位/光比、画幅规则、失败检查和一次定向重试构成。

              

              

                初始结论
                
不是新的渲染模型。它更像“摄影导演 + 质检规程”：把模糊的审美需求，编译成模型可执行、团队可验收的规则包。

QUESTION 01
仓库声明的多人、身份保持与影棚化是否有可见证据？

QUESTION 02
如果底层模型本来就会画棚拍，Skill 的真实增量是什么？

              

                
                
                
              

              

                
背景高频残差2.005 → 0.835固定左上空背景裁区 · −58.35%

                
RGB 通道离散29.901 → 7.307同一裁区 · −75.56%

                
分支变化人脸三角 → 宠物侧向低调光暗侧眼可读，黑毛不做霓虹亮边

              

              
受控结论
主要像素能力来自底层编辑器；Skill 的增量是收束输出空间，让背景、色彩、光向、毛发分离和失败条件更一致。单图单次 A/B 不是统计胜率。

            


            

              
QUESTION 03
在人脸几何满足条件时，文字规则能稳定生成真正闭环 Rembrandt 光吗？

              

                
                
                
                
              

              

                
检查项初次 Skill定向重试

                
身份 / 表情 / 服装通过部分

                
中性连续背景通过通过

                
鼻影—颊影闭环失败失败

                
自然皮肤纹理通过失败

              

              
关键反证
Skill 能规定目标并正确拒绝坏结果，但文本约束不能稳定保证像素级阴影解剖。“失败可审计”本身就是它的重要生产价值。

            


            

              
QUESTION 04
能力能否从单张风格化，扩展到用途画幅与多人共享光向？

              

                
                
                
                
                
              

              
控制方法每个画幅独立一次编辑，不用 CSS 或手工裁图冒充模型能力
身份、服装、主光、背景被锁定，只改变用途几何。
观察边界画幅与关系通过，身份微细节仍会重绘
说明构图规则可执行，但生成式 outpaint 不是无损排版。

H1 · RELIABLE ADAPTER
可靠模型适配层
  • 把诊断、身份锁、画幅和失败项变成结构化参数
  • 连接一个真实图像编辑模型与局部修复流程
  • 保存模型、提示、输入、输出与一次重试的版本
结果：当前工作台从“证据回放”升级为真实单任务执行

            
H2 · MEASURABLE PIPELINE
可测量生产管线
  • 人物/宠物检测、身份相似度与关键点检查
  • 背景噪声、色偏、光晕、裁切与人数自动检测
  • 成本、耗时、失败原因、人工决定和回归 fixture
结果：从“好不好看”变成可比较、可回归的质量系统

            
H3 · PRODUCT SYSTEM
完整产品与治理
  • 账号、任务队列、审批、版本、模板与批量交付
  • 肖像授权、隐私、保留期、删除和审计记录
  • 企业品牌规范、多模型路由、成本与 SLA
结果：能面向家庭、创作者或企业提供真实服务

          

        


        

          
WHAT IT MEANS FOR US
对我们的意义：少走审美试错，建立规则资产，再把它接入可测量系统。

          
01立即可用的专业配方
对单张高情感价值肖像，直接获得主体诊断、身份约束、灯位、背景与失败词。
02团队共同语言
把“感觉不对”变成 closed-loop、身份漂移、背景纹理、光向冲突等可复核检查项。
03可复用的产品内核
同一 schema 可以连接不同模型、QA 指标、任务系统和多种交付面。
04诚实的竞争边界
我们知道模型负责像素，Skill 负责规则，产品价值来自可操作、可度量、可治理的组合。
