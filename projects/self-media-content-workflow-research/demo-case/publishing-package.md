# 手动发布包与状态

## 发布预检

| 能力 | 结果 | 降级 / 下一步 |
| --- | --- | --- |
| 写作 | 三平台演示成稿完成 | 账号负责人做声音微调 |
| 图片 | 有真实 9-seed 主视觉 | 其余图卡按视觉锚排版 |
| 视频原片或录屏 | 未录制 | 按分镜录制正常组 / 故障组终端 |
| 视频合成与字幕 | 未执行 | 提供完整分镜和逐句字幕，可进入剪辑 |
| 公众号草稿 | 未连接、未授权 | 默认交付手动包；授权后也只创建草稿，不群发 |
| 小红书 / 视频发布 | 未连接、未授权 | 用户手动发布 |
| 数据 | 无真实发布数据 | 发布后按 24h / 7d 窗口回填 |

## 小红书清单

- [x] 3 个标题候选
- [x] 8 页图文脚本
- [x] 正文、话题、首评
- [x] 真实主视觉来源
- [ ] 8 页最终成图
- [ ] 手机端逐页审校
- [ ] 用户终稿确认
- [ ] 手动发布授权

## 公众号清单

- [x] 3 个标题候选
- [x] 摘要、作者、正文、主要行动
- [x] 配图和图注要求
- [ ] 最终封面 / 分享图
- [ ] 编辑器排版预览
- [ ] 用户终稿确认
- [ ] 创建草稿授权

## 短视频清单

- [x] 3 个钩子与推荐理由
- [x] 60 秒完整口播和 9 镜分镜
- [x] 逐句字幕、封面、话题与素材缺口
- [ ] 原始录屏 / 真人旁白
- [ ] 1080 × 1920 成片
- [ ] 音画、字幕、安全区和时长核验
- [ ] 用户终稿确认与手动发布授权

## 授权状态

```text
内容方向：DEMO_CONFIRMED
演示成稿：READY_FOR_REVIEW
终稿确认：NO
发布授权：NO
外部写入：NOT_ATTEMPTED
当前状态：AWAITING_USER
```

## 下一步唯一动作

账号负责人选择一个主平台，并明确回复“允许进入该平台的真实终稿 / 草稿阶段”。在此之前不创建草稿、不登录账号、不点击发布。
