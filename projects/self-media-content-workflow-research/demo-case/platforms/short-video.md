# 60 秒短视频发布包（演示成稿）

- 平台：抖音 / 视频号均可适配，发布时需重新核验字段
- 目标受众：正在安装或评估 Agent Skill 的创作者与团队
- 内容目标：用故障对照建立“Skill 不等于模型”的判断
- 目标时长：60 秒
- 出镜方式：真人旁白 + 屏幕录制 / 研究图卡；无数字人
- 一句话核心判断：这个 Skill 不会凭空增加绘画模型，它增加的是知识、作品协议和浏览器质检
- 主要行动：评估下一个 Skill 时先问四个问题

## 钩子

1. 这个 Skill 不会画画，但它抓出了我的作品为什么不可靠。
2. 我跑了 500 个 seed，才发现自己把 Skill 当成模型了。
3. 只改了一行 `Math.random`，4 项测试全亮红。

- 推荐：钩子 3
- 理由：有具体动作、可视化结果和未解释的因果，3 秒内能成立

## 逐句字幕文本

```text
我只把确定性随机换成 Math.random，四项检查立刻失败。
这就是我验证一个生成艺术 Skill 的方式。它不是新的绘画模型。
真正增加的是三层：生成艺术知识、最小作品协议、还有能运行的浏览器工具。
作品接受同一个 hash，能重新渲染，还要暴露 features 和完成状态。
检查器会比较同一个 hash 是否像素一致，也会用 A-B-A 抓全局状态污染。
正常 fixture 全部通过；故障组在重复性、状态和 metadata 上报了四个失败。
然后我跑了 500 个 seed，不再只挑一张好看的，而是看整个系列怎么分布。
但边界也要说：上游版本在 Windows 有兼容问题，同机复现也不等于跨 GPU 一致。
下次看 Skill，问它增加知识、协议、工具，还是权限。别只看宣传语。
```
