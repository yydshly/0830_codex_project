## 精修记录

### 1. favicon 404

- Observed evidence：首轮页面加载成功，但控制台出现 `/favicon.ico` 404。
- Root cause：页面没有声明 favicon，浏览器自动请求默认路径。
- Minimal intervention：加入内嵌 SVG data URL favicon，不新增网络资源。
- Adjacent check：重新加载桌面、平板、手机与 reduced-motion 场景。
- Result：四个场景控制台错误均为空。
- Decision：pass。

### 2. 768px 横向溢出

- Observed evidence：`documentElement.scrollWidth=838`，视口为 768；主体元素边界没有越界。
- Root cause：能力详情面板的装饰性 `::after` 圆环在中等宽度下扩展了根滚动区域。
- Minimal intervention：在 `max-width: 1100px` 下隐藏该纯装饰伪元素。
- Adjacent check：1440、768 和 390 三个视口；能力面板内容与交互保持不变。
- Result：三个视口横向溢出均为 0。
- Decision：pass。

### 3. Revision 2 平板阶段条溢出

- Observed evidence：首轮完整案例检查得到 `scrollWidth=1096`、视口 768；溢出集中在阶段导航与工作台。
- Root cause：平板断点将阶段导航容器改为 `overflow: visible`，横向阶段按钮的 min-content 宽度反向撑开单列网格。

### 4. Revision 3 首屏标题孤行
