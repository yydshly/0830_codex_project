## 创作简报

- 账号定位：以源码、实验和可复现证据研究 AI 工具，而不是复述产品宣传
- 一句话核心判断：`genart-skill` 不是图像模型，而是一套交给编码 Agent 的生成艺术知识、作品协议和浏览器质检工具
- 读者收益：学会用“增加模型 / 增加流程 / 增加工具”三层框架评估 Skill
- 内容形态：小红书 8 页图文、公众号深度文、60 秒短视频方案
- 深度与调性：证据先行、克制、允许讲失败和边界
- 明确不写：不写“自动爆款”“跨设备像素绝对一致”“安装即获得新画风”
- 各平台角度：小红书讲认知反差与检查清单；公众号讲技术原理与实验证据；短视频用 A/B 故障对照形成视觉冲突
- 默认值：以公众号为主平台；不接真实账号；不生成数字人；不虚构发布数据
- 演示方向状态：`DEMO_CONFIRMED`，仅表示案例继续推进，不构成真实终稿或发布授权
