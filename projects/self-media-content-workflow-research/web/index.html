00 / CORE 编排能力

总控工作流

识别请求类型，只加载必要模块，并管理方向、平台、标题、终稿和发布授权。

输入
想法、链接、素材、数据或“继续上次任务”
处理
路由请求、推进状态、触发质量门、发现可用工具
产物
任务卡、阶段产物、状态和下一步唯一动作
依赖
核心流程无厂商硬依赖；外部动作按环境适配
边界

终稿确认不等于发布授权；任何外部写操作都要单独确认。
