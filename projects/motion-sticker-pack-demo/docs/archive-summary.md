## 一句话结论

这个库不是图片模型或视频模型，而是一套把生成模型包进审批、路由、降级、后处理和交付合同中的动态贴纸 Agent Skill。

## 我们确认的能力

1. 接收角色参考图、文字角色、现成图板、整板视频或独立贴纸。
2. 整理身份锚点、静图提示词、动作语义和逐格任务。
3. 用图片与布局 SHA-256 固定审批状态，避免静图变化后继续使用旧批准。
4. 在原生视频工具、外部 Provider、关键姿态、本地仿射和 Prompt-only 之间路由与降级。
5. 检测网格、切格、边缘连通色键去背、规范画布、编码 WebP/GIF/PNG、生成质检报告并打包 ZIP。
6. 对失败格、伪 Alpha、循环、静止段抖动、尺寸、帧率和文件预算保留机器可读证据。

## 原理与职责边界

```text
角色/贴纸输入
  → Agent：理解身份、编译提示词、维护审批与路由状态
  → 图像/视频模型：生成真实像素和语义运动
  → 确定性程序：检测、切格、去背、编码、QC、报告、ZIP
  → 人：批准静图、授权外部费用、评审身份与动作质量
```

因此，仓库交付质量来自三层协作，而不是仓库自带一个通用视频大模型。视频 Provider 可以替换；审批、状态、失败降级和交付格式仍然复用。

## 已完成的证据

- 固定上游 `main` 提交 `6531b37`，保留 498 个跟踪文件并移除嵌套 Git 元数据。
- 检查 Skill、29 个执行脚本、14 个测试文件、五类外部视频 Adapter 和上游黑猫真实贴纸包。
- 用宠物、小龙、耳机、儿童故事、商品卖点和汉字知识素材覆盖六类业务场景。
- 实跑 `transform-local`，确认它只能做整图仿射循环，不能冒充语义动作。
- 实跑 `keypose-local`，交付小龙、耳机和小狗三组内部姿态确实变化的 Animated WebP/GIF/PNG/ZIP。
- 建立提示词工作台，由项目生成提示词、用户选择并操作外部视频平台。
- 接收一份用户生成的 768×768、24fps、6.58 秒小龙 MP4；固定上游脚本完成 53 帧绿幕去背和 240×240、8fps 透明贴纸交付。
- GIF 771,943 bytes，低于 1MiB；保留模型重建首姿、背景漂色和 `residual-hold-jitter` 限制。

## 适用场景

| 场景 | 价值 | 主要风险 |
| --- | --- | --- |
| 品牌吉祥物与社群反应 | 让同一角色形成可审批、可版本化的表情资产 | 身份和品牌色漂移 |
| 宠物与个人表达 | 从复杂毛发照片扩展日常情绪贴纸 | 透明边缘、暗部细节 |
| 儿童角色内容 | 用温和循环复用故事人物 | 动作安全和角色一致性 |
| 商品营销 | 把产品结构和卖点符号转成短循环 | 商品几何、文字和商标变形 |
| 教育微解释 | 把知识部件按步骤组合成时间线 | 事实与顺序正确性 |
| 存量资产迁移 | 把旧图板、视频和独立贴纸统一成多格式包 | 网格误检、跨格污染、平台限制 |

## 可扩展方向

1. Telegram WebM、Discord APNG 等平台专用交付与自动预算。
2. 可复用动作语义 DSL，让“庆祝、挥手、翻译传递”等动作跨角色保持可读。
3. 时序 Alpha、溢色和运动模糊边缘修复。
4. 身份保持、循环质量、静止段抖动和失败格的自动评分与阻断。
5. 角色圣经、审批版本和历史资产可复现治理。
6. 结合质量、隐私、配额和价格的 Provider 路由与重试审计。

## 对我们的意义

最值得复用的不是某个贴纸风格，而是“生成中间层”：把不稳定且可替换的模型调用，转成有输入合同、人工门、状态绑定、诚实降级、质量证据和标准交付物的生产任务。这个模式可以迁移到广告短片、产品演示、角色内容和其他多媒体 Agent 工作流。

## 暂时归档与恢复条件

当前研究问题、代表样例、真实视频回传、透明交付、网页展示和工程验收均已完成，因此项目暂停归档。以下任一目标明确时恢复：

- 需要实测并比较新的图生视频 Provider；
- 需要开发具体聊天平台的投稿格式；
- 需要用时序分割改善发丝、阴影或运动模糊；
- 需要比较整板生成与逐格生成的成本、返工率和跨格污染；
- 需要把审批、QC 与角色版本治理接入长期生产系统。
