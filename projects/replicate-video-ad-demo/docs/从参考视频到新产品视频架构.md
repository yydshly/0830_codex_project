# 从参考视频到新产品视频架构

## 一句话共识

这个样例不是“把 AirPods 广告换皮”，而是把一条已经被市场验证过的参考视频当作研究材料，提取它的广告表达机制，再把这些机制重组为另一产品可以独立执行的视频生产架构。

拆解完成后，生成阶段原则上不需要继续把原片交给视频模型。真正进入生产的是结构蓝图、真实产品事实、品牌资产、连续性约束和分段 Prompt。

## 这个样例证明了什么

它证明了一条参考视频可以经过以下转换：

```text
参考视频
  ↓ 一次性证据抽取与分析
可复用的广告表达机制
  ↓ 注入新产品事实与场景
新产品视频生产架构
  ↓ 视频模型分段生成 + 剪辑
最终成片
```

这里复用的是：

- 信息出现的顺序；
- 问题、触发、变化、证明、回报之间的因果链；
- 镜头节奏和空间难度如何递进；
- 抽象功能如何变成可观察的行为结果；
- 商品主张在什么时候出现，以及需要什么证据；
- 人物、产品、服装、色彩和运动方向如何保持连续。

这里不复用的是：

- 原片人物或名人肖像；
- 原片品牌、产品造型和视觉系统；
- 原片具体镜头、动作编排、场景路线；
- 原片音乐、声音、字幕和广告文案；
- 原产品的性能主张。

## 三层能力模型

### 第一层：一次性拆解层

输入是参考视频，任务是建立可复核证据。

| 输入 | 处理 | 输出 |
|---|---|---|
| 参考视频 | 视频探测、抽帧、故事板、时间映射、音频准备 | 关键帧、时间戳、Manifest、故事板 |
| 证据帧与音频 | 观察人物、产品、动作、空间、声音与文字 | 只包含观察事实的镜头记录 |
| 镜头记录 | 标注 Hook、Escalation、Bridge、Proof、Payoff、CTA | 广告结构时间线 |

这一步需要原片。它的目的不是让模型记住原片画面，而是把“我觉得它很好”变成可定位、可讨论、可复核的证据。

### 第二层：可复用架构层

输入是证据和新产品资料，任务是完成结构迁移。

它的核心产物包括：

1. 每一段的时间范围与剧情功能；
2. 必须保留的表达机制；
3. 必须替换的人物、场景、产品和品牌元素；
4. 新产品的“问题 → 触发 → 感知变化 → 行为证明 → 商品收口”因果链；
5. 跨段连续性锚点；
6. observed、adaptation、placeholder 三种商品主张状态；
7. 主提示词、分段生成计划、负面约束和后期文案位置。

这套架构才是 Skill 的主要交付物。它可以脱离原片独立存在，也可以重复交给不同视频模型、不同导演或不同剪辑团队执行。

### 第三层：生成执行层

输入是第二层架构和真实生产素材，任务是形成最终成片。

```text
生产架构
+ 产品真实事实
+ 产品外观参考 / 品牌资产
+ 视频生成模型
+ 声音、字幕、Logo 与剪辑
= 最终视频
```

这一层通常不需要再把原片作为视频生成条件。原片可以保留在研究和质量检查环节，用来确认节奏功能是否完整，但不应该成为复制画面的依据。

## “只用拆解后的能力构造视频”是否成立

结论分两部分：

### 结构上：成立

只要第二层产物完整，后续可以使用拆解后的生产架构设计和生成新视频，不必持续引用或输入原片。这样做还有三个好处：

- 减少生成结果过度接近参考作品的风险；
- 让同一结构可以迁移到完全不同的产品和场景；
- 便于用同一规格比较不同视频模型、成本和生成策略。

### 生产上：仅有结构还不够

至少还需要以下四类输入：

| 必需输入 | 解决的问题 | 缺失风险 |
|---|---|---|
| 真实产品事实 | 产品到底能做什么、哪些主张可发布 | 幻觉参数、违法或无法证明的宣传 |
| 产品与品牌资产 | 产品长什么样、Logo、色彩、字体和包装 | 设备漂移、品牌不一致、造型撞车 |
| 视频生成能力 | 把分段 Prompt 变成连续画面 | 只有方案，没有镜头素材 |
| 后期制作 | 剪辑、调色、声音、字幕、Logo、脚注 | 镜头无法形成可投放成片 |

因此更准确的说法是：

> 我们可以只使用拆解后的结构能力来“设计和约束”新视频，但要得到最终成片，仍然需要真实产品输入、生成工具和后期生产。

## 本案例中的具体迁移

| 原片观察 | 抽象机制 | Relay Arc 新片表达 |
|---|---|---|
| 耳机先进入画面 | 一个动作触发状态改变 | 球员触碰黑色翻译耳机 |
| 人物由静止变为舞动 | 抽象功能变成身体状态 | 多语言混乱收束，球员恢复专注 |
| 从房间进入走廊 | 用空间推进延长产品体验 | 从球员通道走向比赛任务 |
| 干扰、距离和速度升级 | 提高环境难度形成证明 | 多人高速比赛考验理解能力 |
| 在复杂街道保持节奏 | 用行为结果证明功能 | 根据战术完成同步传跑与进球 |
| 主张与产品定格 | 结果之后再命名产品价值 | 经验证参数占位 + 原创设备英雄镜头 |

迁移后的核心链路是：

```text
赛前多语言压力
→ 触碰翻译耳机
→ 混乱声音收束为清晰语义
→ 把理解带入球场
→ 团队同步完成进攻
→ 产品与经验证主张收口
```

## 推荐的实际工作流

1. 选择一条表达机制值得借鉴、来源明确的参考视频。
2. 运行抽帧器，建立时间戳、关键帧和故事板证据。
3. 只写观察到的事实，避免过早把解释当成事实。
4. 标注每一段的剧情功能和前后因果。
5. 把结构抽象成不含人物、品牌和具体画面的机制描述。
6. 输入新产品目标用户、问题、卖点、场景与可验证参数。
7. 完成结构迁移、连续性锚点、主张状态和分段 Prompt。
8. 冻结生产架构；生成阶段默认不再输入原片。
9. 用产品参考图和架构分段生成镜头。
10. 剪辑、调色、声音、字幕与法务脚注在后期完成。
11. 用架构逐段检查成片，而不是检查它“像不像原片”。

## 作为长期能力沉淀

当前 AirPods → Relay Arc 只是这套方法的第一个真实示范。库的长期资产不是该案例的六段内容，而是可以在后续类似任务中直接复用的：

- 媒体证据抽取工具；
- 功能级广告分析方法；
- 结构迁移与商品事实控制；
- 连续性和分段生成规范；
- 后期、法务与交付检查；
- 有 Skill / 无 Skill 的评估方式。

后续遇到新的优秀视频时，应复用这套能力和模板，重新填写参考片、目标产品、真实事实、品牌资产和生产条件。详细入口见 [《能力沉淀与复用指南》](能力沉淀与复用指南.md)。

## Skill 的研究价值

大模型已经可以直接理解视频并写提示词，所以研究问题不是“没有 Skill 能不能做”，而是：

- Skill 能否让不同轮次得到更稳定的结构？
- 能否减少人物、产品和场景连续性错误？
- 能否降低商品主张幻觉？
- 能否提高生成素材的可剪辑率？
- 能否减少返工次数、时间和模型成本？

最有说服力的验证方式是同模型、同预算、同产品做 A/B：

- A 组：只给“参考这个广告做一条类似视频”的泛化指令；
- B 组：只给拆解后生产架构、产品事实和产品资产，不再输入原片；
- 盲评：镜头因果完整度、产品连续性、宣称准确性、可剪辑率、返工次数与总成本。

## 术语约定

| 术语 | 本项目中的含义 |
|---|---|
| 复刻 | 复用表达机制和生产结构，不复制具体作品 |
| 拆解能力 | 把参考片转换为证据、剧情功能和约束的方法 |
| 生产架构 | 可以独立指导生成与剪辑的镜头规格，不是软件架构 |
| Skill | 约束 Agent 分析和输出的方法规范，不是视频基础模型 |
| 成片 | 经生成、剪辑、声音、文字和品牌处理后的最终 MP4 |

## 能力边界

- Skill 不负责训练或替代视频生成模型。
- Skill 不自动获得参考作品的使用授权。
- Skill 不验证产品参数，商品事实必须由产品、测试和法务提供。
- Skill 可以设计镜头和 Prompt，但不能保证任意模型一次生成成功。
- 当前案例完成的是证据、架构、概念分镜和生产包，不是最终视频成片。
