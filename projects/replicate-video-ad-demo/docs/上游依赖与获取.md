## 为什么公开仓库不内置上游源码

获取该提交时，上游仓库没有提供 `LICENSE` 文件。没有明确许可证不等于获得再分发授权，因此本项目只公开我们原创的研究记录、模板、网页、测试脚本和实验产物，不把上游源码快照提交到远端。

使用或再分发上游代码前，请自行核对仓库当前许可状态，并在必要时向作者取得授权。

## 本地获取

确认有权使用后，在本项目目录执行：

```powershell
git clone https://github.com/Jingyi-Wu-Richael/replicate-video-ad.git upstream
git -C upstream checkout e143d2a7bc0d7c684b8164291799fe1ff48ed7dc
```

也可以把已授权的 `extract_video.py` 放在任意位置，并通过 `-ExtractorPath` 传给运行脚本。

## 运行抽帧器

```powershell
./demo/run_extractor.ps1 `
  -InputPath path/to/authorized-reference.mp4 `
  -OutputDir artifacts/replay-output
```

自定义抽帧器路径：

```powershell
./demo/run_extractor.ps1 `
  -InputPath path/to/authorized-reference.mp4 `
  -OutputDir artifacts/replay-output `
  -ExtractorPath path/to/extract_video.py
```

输入视频必须是本地、已获授权的文件；输出目录应为新目录或空目录。完整参考视频不应提交到本仓库。
