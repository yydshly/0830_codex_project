# 热门广告结构迁移生产包

## 0. How to Use This Pack

这个文件是可以脱离参考视频执行的“新产品视频生产架构”，不是原片模仿指令，也不是最终成片。

推荐使用方式：

```text
本生产包
+ 真实产品事实
+ 产品外观参考与品牌资产
+ 视频生成模型
+ 剪辑、声音、字幕与法务脚注
= 最终视频
```

进入正式生成后，默认不再把 Apple 原片作为视频模型输入。原片只保留在研究与质量检查环节，用于确认 Hook、状态变化、难度升级、结果证明和产品收口是否完整；不要用“是否像原片”作为成片标准。

生成前必须补齐：

- 产品外观参考：正侧背面、佩戴关系、材质与尺寸；
- 品牌资产：最终品牌名、Logo、色彩、字体与包装；
- 商品事实：支持语言、翻译延迟、测试条件、续航、防护等级与上市信息；
- 生产选择：视频模型、分辨率、帧率、单段时长、角色参考和预算；
- 后期资产：音乐授权、声音设计、字幕、CTA、脚注与交付规格。

如果上述资料尚未提供，保留本包中的占位符，不允许视频模型自动补全。

### 观察与假设

- observed：原片由人物佩戴耳机开始；空间从静态室内扩展到走廊、服务区和繁忙街道；结尾出现 ANC 主张与产品锁定。
- observed：画面明确出现 Apple 的主动降噪主张，但本项目没有独立核验该主张。
- adaptation：新片把“环境压力中保持自己的节奏”改写为“多语言协作压力中恢复团队同步”。Relay Arc 及其“实时翻译”能力是本研究的虚构叙事前提，不代表真实产品能力。
- placeholder：迁移到真实产品时，是否支持翻译、触发方式、适用环境、准确率、端到端延迟、支持语言、续航、防护等级和上市信息全部待商品证据与法务确认。

## 3. Adaptation Logic

### 本案例采用的功能级架构约束

1. 一个无需对白即可看懂的产品触发动作。
2. “触发前 → 感知改变 → 行为结果”的完整因果链。
3. 空间难度逐级提高，而不是六张互不相关的漂亮画面。
4. 情绪和任务结果先完成，商品主张与产品定格后出现。

### 目标片的独立设计决策

1. 明星改为无名虚构球员；酒店与城市改为球员通道和球场。
2. 白色柄状耳机改为黑色挂耳设备，避免 Apple 工业设计。
3. “降噪后的个人节奏”改为“理解战术后的团队同步”。
4. 原片音乐、动作编排、文案和品牌视觉全部重新设计。

六段节拍和 35 秒时长是本案例根据原片与目标概念做出的设计选择，不是所有产品广告必须套用的固定模板。迁移到真实项目时，产品事实、受众和沟通目标优先于参考片结构。

### 连续性锚点

- 同一位虚构年轻男性球员，短黑发，石墨训练服，单条电光青缝线。
- 同一对哑光黑、紧凑、无耳机柄的挂耳设备；青色状态光。
- 色彩由压迫阶段的暖琥珀逐步过渡到理解阶段的冷青色。
- 主体运动方向从画面深处向球场推进；不在分段生成时镜像翻转。

## 4. Copy-Ready Master Prompt（全片创意与连续性总纲）

以下内容用于统一全片创意、人物、产品、场景和因果关系，不建议作为一次生成 35 秒视频的单一请求。实际执行应使用第 6 节拆成四段，并在每段加入目标产品参考图、角色锚点和上一段尾帧；这些新产品素材取代原片成为视觉条件。

生成一条 35 秒、16:9、24 fps 的电影级运动科技产品发布广告。画面内不得生成任何可读文字、字幕、标识或界面；所有商品文案在后期加入。

主角是同一位完全虚构的年轻男性足球运动员：短黑发、运动员体型、石墨色训练夹克、单条电光青缝线、黑色训练裤。他从头到尾佩戴同一对哑光黑色 AI 实时翻译运动耳机：紧凑挂耳造型、无白色、无耳机柄、无 Apple 设计特征，设备上只有一条很弱的青色状态光。不得出现任何真实名人相貌。

开场位于比赛前的球员通道。多位教练和队友同时用不同语言快速交谈，暖红、橙、琥珀色的声音轨迹从不同方向交叠压向主角。他站在人群中心，努力判断信息，呼吸紧，视线短暂失焦。以近景和手持运动感建立压力，不使用 UI 解释问题。

切到极近景：主角用食指轻触黑色挂耳设备，触点亮起一条青色光。匹配剪辑回到他的脸，四周交叠的暖色声音轨迹开始减弱、分离，最后收束成一条干净的青色语义波形抵达耳边。他的下颌放松、眼神重新锁定前方。让能力通过状态变化被看见，不显示任何翻译字幕。

同一镜头运动链继续跟拍主角穿过通道走向球场。教练在前方给出最后指令，细微青色声音轨迹把教练、主角和一名队友连成一个明确关系。保持同一人物、服装、设备和向前运动方向。灯光从通道的暖暗逐步过渡到球场的冷青与白色体育场灯。

进入球场后提高难度：比赛速度、多人跑位、观众能量和空间尺度迅速增加。主角接收队友信号，提前启动，完成一次同步跑位、传球和回接；不要用悬浮界面替代人物行动。宽镜头展示团队协作，中近景捕捉主角听懂后的确定表情，动作必须符合真实足球运动逻辑。

在一次决定性进攻中，主角与队友完成同步传跑，形成射门并得分。以任务结果作为“理解成功”的可见回报。镜头保持高级国际运动品牌广告质感：深黑、高反差、电光青与体育场暖琥珀，真实皮肤、真实织物、受控运动模糊、电影级方向光。

最后从球场青色光带匹配切到产品英雄镜头：同一对哑光黑挂耳设备悬浮在黑到青的渐变表面上，轮廓光清楚展示挂耳结构和紧凑机身，留出足够负空间供后期加入“Relay Arc / Hear the play.”及经确认的商品事实。结尾干净、克制、无 Apple 视觉语言。

声音设计：开场使用多方向、不同语言、略有重叠的战术碎片与通道混响；触碰时出现一个短促、干净的青色音色；之后把多声源收束为一个清晰但不泄露具体商品承诺的语义声道；球场段加入鞋钉、呼吸、传球和观众声；产品定格时留下一个简短上升音标。不要复制参考片音乐或音效。

## 5. Post-Production Copy

推荐文案结构（全部后期加入）：

1. 品牌 / 产品：`Relay Arc`
2. 情绪句：`Hear the play.`
3. 商品事实：`【支持语言数：经产品与法务确认】`
4. 性能事实：`【端到端翻译延迟：经测试确认】`
5. CTA：`【上市日期 / 官方页面】`
6. 测试脚注：`【测试条件、设备版本、网络条件和统计口径】`
7. 核心功能：`【确认产品是否具备实时翻译能力及适用条件】`
8. 触发方式：`【确认触碰设备是否为真实交互方式】`

不建议把“世界第一”“零延迟”“100% 准确”等无法证实的绝对化表述写进画面。

## 6. Segmented Generation Plan

### Segment A · 00:00–00:08 · 压力与触发

- 生成内容：球员通道压力、多人声音轨迹、触碰设备、声波开始收束。
- 必须锁定：人物脸型、服装、耳机侧面造型、暖色压力光。
- 尾帧：触碰后的近景，青色状态光刚亮起，作为 Segment B 首帧条件。

### Segment B · 00:08–00:17 · 理解与空间推进

- 生成内容：暖色混乱转为单一青色波形；跟拍进入通道深处。
- 必须锁定：同一人物与设备；运动方向持续向画面深处；青色逐渐占优。
- 尾帧：球员与教练共同朝球场出口前进，作为 Segment C 首帧条件。

### Segment C · 00:17–00:29 · 比赛压力与结果

- 生成内容：多人协作、跑位、传球、回接和得分。
- 必须锁定：真实足球动作、同一服装、同一设备、队友位置关系。
- 尾帧：进球后的稳定中近景，主角转头看向队友，青色球场灯作转场素材。

### Segment D · 00:29–00:35 · 产品定格

- 生成内容：青色灯带匹配剪辑到产品英雄镜头；设备轻微旋转后稳定。
- 必须锁定：哑光黑挂耳结构、无白色耳机柄、无标识、干净负空间。
- 后期：加入品牌、CTA、已验证参数和测试脚注；不得要求视频模型生成文字。

## 7. Negative Constraints

- 不出现 Vini Jr. 或任何可识别名人；不克隆声音。
- 不出现 Apple、AirPods、苹果图形或白色柄状耳机；不模仿 Apple 产品定格版式。
- 不复用参考片具体舞蹈、酒店场景、城市路线、音乐、字幕或镜头构图。
- 不自动继承“世界最佳主动降噪”等原片主张。
- 不生成可读文字、乱码字幕、漂浮 UI、赛博 HUD 或无叙事功能的参数图标。
- 不改变人物身份、服装、设备形状、佩戴侧、色彩锚点或运动方向。
- 避免畸形手指、穿模耳机、不真实足球动作、重复球员、错误球门结构和过量运动模糊。

## 8. Editing & Finishing Plan

1. **选片**：每段生成多个候选，只保留人物身份、产品外形、运动方向和动作逻辑连续的镜头。
2. **拼接**：优先使用动作匹配、方向匹配和青色光带做段间连接；不得插入原片镜头。
3. **连续性复核**：逐镜检查人物脸型、训练服、耳机佩戴侧、设备比例、球员位置和球的运动轨迹。
4. **声音重建**：重新录制或合成多语言战术片段、鞋钉、呼吸、传球、观众声与产品音标；不得使用原片音轨。
5. **音乐授权**：选择已授权音乐或原创配乐，节拍服务六段结构但不复制原片旋律与编曲。
6. **调色**：压力段以暖琥珀为主，理解与执行段逐步引入青色；产品定格回到黑青高反差。
7. **文字与品牌**：字幕、Logo、CTA、参数和测试脚注全部在后期加入，避免视频模型生成乱码。
8. **商品事实复核**：发布前逐项确认核心功能、触发方式、场景适用性、性能数字、测试口径与法务表述。
9. **导出**：根据投放渠道分别输出 16:9 主片与经重新构图的短版；不得直接裁切导致产品或脚注缺失。

## 9. Handoff Note

这个包是“证据约束后的生成架构”，不是最终视频。它在结构冻结后应当可以脱离原片执行。

先用相同模型和预算做一次 A/B：A 组给“参考原片做一条类似视频”的泛化指令；B 组不输入原片，只输入本包、真实产品事实和产品资产。盲评镜头因果完整度、人物 / 商品连续性、宣称幻觉、可剪辑率、返工次数与总生成成本，才能回答 Skill 是否带来稳定增益。
